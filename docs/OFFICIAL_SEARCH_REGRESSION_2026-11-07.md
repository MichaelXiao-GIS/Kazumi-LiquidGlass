# 官方番剧搜索修复与测试版 0015

版本：`2.4.3+20406`，标签：`v2.4.3-ios27.1-test.r0015`。

## 原因与修复

0014 的源码已经整合上游 Kazumi 2.4.3。关键词搜索失败并非没有更新客户端，而是默认镜像模式将 `POST /v0/search/subjects` 转发到镜像服务；这个接口要求上游应用签名，本分支没有相应凭据，返回 401。

本版直接调用 Bangumi 官方公开搜索接口 `https://api.bgm.tv/v0/search/subjects`。镜像模式的搜索不再转发、不附加镜像签名；直连模式使用官方接口，ECH 模式仍通过原有 ECH 传输访问官方接口。复用现有代理、超时、错误映射及分页处理。其它条目请求继续按用户的加速设置处理。

请求 User-Agent 按官方要求标识本仓库、应用版本和实际系统。网络设置中注明镜像模式的搜索使用官方接口；401/403 提示改为官方服务拒绝请求，避免建议用户在两条实际相同的搜索线路之间反复切换。保留请求失败与有效空结果的区别、重试和分页恢复。

依据：[官方搜索规范](https://github.com/bangumi/api/blob/master/open-api/v0.yaml)、[官方 User-Agent 要求](https://github.com/bangumi/api/blob/master/docs-raw/user%20agent.md)。
