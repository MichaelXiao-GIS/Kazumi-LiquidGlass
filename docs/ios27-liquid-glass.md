# Kazumi · iOS 27 / iPhone Duo

这个分支基于上游 `7cb58d7d`（2.4.2），保留 Flutter、采集规则、弹幕、收藏、同步和播放服务，调整导航与自适应布局。

## 界面

- iOS 导航使用 UIKit `UIGlassEffect`，支持系统深浅色、iOS 27 透明度偏好、降低透明度和增强对比度；iOS 15–25 使用系统材质回退。
- 悬浮标签栏、独立搜索按钮、SF Symbols、系统字体、圆角内容卡片与分组设置。玻璃用于悬浮导航，标题栏与内容使用同色背景，避免矩形玻璃边缘产生分隔线。
- 标签栏支持沿排列方向拖动：原生玻璃水滴随手指移动并预览目标标签，松手后切换一次；取消或在栏外松手会还原。水滴使用 clear 玻璃材质，图标和文字绘制在其上方，避免选中项被模糊遮住。横向底栏和竖向侧栏使用同一手势逻辑，搜索按钮独立。旋转、页面覆盖或外部切换会取消拖动；减少动态效果时不拉伸，VoiceOver 保留普通按钮操作。
- 悬浮操作按钮的背景按完整按钮宽度绘制；“开始观看”和“保存并测试”等带文字按钮使用胶囊形，避免圆形背景只覆盖部分文字。
- 详情页“开始观看”在向下浏览后平滑收为 56×56 的播放按钮，回到顶部再展开；按钮右边缘保持固定，点击与辅助功能提示不变。切换详情标签不会误展开，减少动态效果时立即调整尺寸。
- 导航按实际可用空间切换底栏/侧栏。iOS 27.1 的 `UIView.reservedRegions(kind:)` 通过场景桥接获取遮挡与折叠分区；右侧系统区域出现时，导航在其下方竖排。
- 主路由出口在尺寸变化时保持同一个组件位置，保留路由与滚动状态。
- iOS 列表延伸到屏幕底边，安全区和悬浮底栏的避让空间放在可滚动内容末尾，避免海报被底部横条提前裁断。底部叠加可透出内容的渐变模糊层，触控与滚动可穿过；降低透明度或增强对比度时使用实色回退。
- 主页面被覆盖或正在切换时，原生玻璃导航退出挂载并立即隐藏 UIKit 材质；返回动画完全结束后再创建。避免侧滑返回时底层侧栏的玻璃边缘穿过当前页面，取消侧滑也不会提前恢复导航。弹出对话框保留原有导航。
- 热门海报按内容区域宽度与文字缩放计算列数，避免侧栏展开后仍按整屏宽度布局。
- 推荐列表在 MobX Observer 内读取列表快照，使首次请求、分页追加和标签查询完成后立即刷新，修复冷启动必须先切换标签才能显示内容的问题。
- 播放页支持窄屏上下布局、宽屏视频/选集双栏、系统报告的水平/竖直折叠分区布局和显式全屏。播放器组件在布局切换时保持挂载。
- 展开的宽屏使用左右分栏：左侧整列为黑色播放区域，视频按原始比例居中；右侧显示选集和评论，两栏直接相接。播放背景延伸到安全区，控件单独避让；全屏侧栏固定覆盖窗口，收起时不会将播放容器压成零尺寸，选集组件也不会重复挂载。
- iOS 点击全屏会主动请求横屏，无需先旋转手机；退出全屏、关闭播放页后释放方向限制，连续点击按顺序处理。
- iOS 播放控制改为左上标题胶囊、右上“选集 / 更多”胶囊和底部居中的玻璃控制条。视频背景铺满播放区域，保持视频原比例；只对实际与相机重叠的标题或控制条做局部水平避让，内屏及普通比例窗口保持居中。
- 播放页隐藏系统时间与 Wi-Fi 状态区，退出后恢复；竖屏视频和下方选集内容使用全宽，不再为相机保留整列空白。
- 播放菜单支持渐显、缩放与退出动画；修复 iOS 自适应滚动条重复套用窗口安全区后出现在菜单中间的黑线。菜单保留触摸滚动，减少动态效果时直接切换。

- 侧栏导航、搜索与返回顶部共用系统状态区中轴；有摄像头遮挡时采用摄像头中心，内屏补偿状态区预留范围的外侧留白。
- iOS 设置首页及二级设置内容延伸至底部安全区，使用渐变半透明模糊；最后一项仍可滚动至安全区上方。
- 推荐页在侧边导航模式下将回顶按钮放入导航区域、位于搜索下方；内外屏不遮挡海报，空间不足时保留原按钮。

## 构建

需要 Flutter **3.47.7**、Xcode **27.1 或更新**、CocoaPods、CMake >= 3.22 和 Ninja。SDK 版本与最低运行版本是两回事：构建使用 iOS 27.1+ SDK，Flutter 3.47.7 要求最低运行版本 **iOS 15**。

```sh
flutter pub get
flutter analyze --no-fatal-infos
flutter test
bash tool/build_ios27.sh
```

`dist/Kazumi_iOS27_unsigned.ipa` 是未签名包，需要自己的 Apple 开发者签名或侧载工具重新签名。脚本没有上传、发布或修改远端仓库。

iOS 图标原图保存在 `assets/images/logo/logo_ios.png`，透明区域按深棕色合成的构建源为 `logo_ios_opaque.png`。预先合成可避开 flutter_launcher_icons 0.14.4 的半透明像素颜色通道计算错误；原图保持不变。`flutter_launcher_icons.yaml` 固定使用该构建源；运行 `dart run flutter_launcher_icons` 可重建所有 iOS 尺寸。生成的 `AppIcon.appiconset` 一并提交，后续打包无需重新生成；其他平台图标不受影响。

替换原图时可用 FFmpeg 更新不透明构建源，再生成尺寸资源：

```sh
ffmpeg -f lavfi -i 'color=c=0x554943:s=1024x1024' -i assets/images/logo/logo_ios.png -filter_complex '[0:v][1:v]overlay=format=auto:shortest=1,format=rgb24' -frames:v 1 -update 1 -y assets/images/logo/logo_ios_opaque.png
dart run flutter_launcher_icons
```

GitHub 的 iOS 构建会先检查 SDK；运行器必须安装并选择 Xcode 27.1+。如果系统有多个 Xcode，可以设置 `DEVELOPER_DIR=/Applications/Xcode_27.1.app/Contents/Developer`。

## 验证范围

自动化布局测试位于 `test/adaptive_layout_test.dart`，覆盖窄屏/宽屏/矮窗口、字号放大、不对称安全区域、折叠时路由和播放器状态保留、双栏、水平/竖直折叠分区及弹出面板避让、顶栏全宽及深浅色像素连续性。

`test/ios_navigation_transition_test.dart` 覆盖窄屏/宽屏的返回动画、取消和完成交互式侧滑、多级返回、滚动状态保留、对话框及原生视图销毁前立即隐藏。

`test/ios_scroll_edge_test.dart` 覆盖底边内容像素连续性、实际背景模糊、触控穿透、增强对比度回退，以及窄屏底栏/宽屏侧栏模式下最后一排海报和按钮的避让。

`test/video_layout_regression_test.dart` 覆盖展开手机的左右分栏及整列播放区域、底边/相机安全区的黑色像素连续性，以及播放组件在全屏、选集侧栏和返回操作中保持挂载（包括侧栏展开时退出全屏）。旧版的零尺寸全屏和安全区缺口已通过回归检查复现。

`test/popular_loading_test.dart` 覆盖首次异步返回、原列表分页追加及标签异步返回；三项均在修复前复现失败。`ios/RunnerTests/RunnerTests.swift` 覆盖原生拖动预览与一次提交、栏外松手/取消、旋转/隐藏中断，以及竖向拖动和独立搜索。

`test/info_watch_button_test.dart` 在真实详情页的窄屏和宽屏布局中覆盖播放按钮随滚动收起、切换标签后保持收起、回顶展开、尺寸及右边缘位置。收起与展开均检查多个中间帧的实际 Material 背景宽度连续变化，而非只检查外层占位或最终状态；中间帧检查在 test.7 复现按钮背景立即缩成 56 的问题。

`test/player_glass_controls_test.dart` 覆盖相机四角的局部避让、普通窗口与内屏居中、旋转期间旧场景几何丢弃、竖屏全宽和两倍文字缩放下的控件操作。`test/player_glass_menu_test.dart` 在 iOS 主题下覆盖菜单打开/关闭中间帧与异常 Cupertino 滚动条移除；`test/video_fullscreen_orientation_test.dart` 覆盖全屏进入、退出、关闭与连续请求，`test/video_system_bars_test.dart` 覆盖播放页状态区隐藏与返回恢复。

## 发布前检查

发布前仍需在 Device Hub 的 iPhone Duo 模拟器和真机完成以下完整回归：

1. 外屏与内屏之间切换、四个旋转方向、半折叠和左右分屏。
2. 导航、搜索、弹出菜单和播放器控件避开相机、状态区域与折线。
3. 播放过程中折叠保持集数、播放进度、弹幕与音频连续；全屏和画中画返回正常。
4. 系统深浅色、透明度滑块、降低透明度、增强对比度、减少动态效果、VoiceOver 和大字号。
5. 真实规则源搜索、解析、下载和后台播放；自动化布局测试不替代联网播放或设备验证。
