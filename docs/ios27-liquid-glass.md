这个分支初始基于上游 `7cb58d7d`（2.4.2），当前源码已整合上游 `4ca04009`（2.4.4），保留 Flutter、采集规则、弹幕、收藏、同步和播放服务，调整导航与自适应布局。

测试版 0018 恢复播放页选集、评论底部的渐变模糊。宽屏分栏在原生侧栏隐藏且右侧没有遮挡时，将侧栏额外占用的宽度分给视频，同时保留选集面板的可用宽度和窗口自身的安全边距。

## 界面

- iOS 主导航使用 UIKit 的 `UITabBarController`。系统负责各版本的标签外观、交互和辅助功能。iOS 26 及更新系统提供 Liquid Glass，iOS 15–25 使用对应版本的系统标签栏。
- 悬浮标签栏、独立搜索按钮、SF Symbols、系统字体、圆角内容卡片与分组设置。玻璃用于悬浮导航，标题栏与内容使用同色背景，避免矩形玻璃边缘产生分隔线。
- 系统标签包括推荐、时间表、追番和我的，均配置了文字和 SF Symbol。按住并拖动时，UIKit 呈现选择反馈并处理落点。搜索使用系统搜索标签打开 Flutter 搜索页，返回后恢复之前的标签。
- 悬浮操作按钮的背景按完整按钮宽度绘制；“开始观看”和“保存并测试”等带文字按钮使用胶囊形，避免圆形背景只覆盖部分文字。
- 详情页“开始观看”在向下浏览后平滑收为 56×56 的播放按钮，回到顶部再展开；按钮右边缘保持固定，点击与辅助功能提示不变。切换详情标签不会误展开，减少动态效果时立即调整尺寸。
- iPhone Duo 上，UIKit 根据窗口和系统保留区域决定标签栏的边缘与排列方向。播放布局继续使用场景报告的遮挡和折叠分区。
- 主路由出口在尺寸变化时保持同一个组件位置，保留路由与滚动状态。
- iOS 列表延伸到屏幕底边，安全区和悬浮底栏的避让空间放在可滚动内容末尾，避免海报被底部横条提前裁断。底部叠加可透出内容的渐变模糊层，触控与滚动可穿过；降低透明度或增强对比度时使用实色回退。
- 详情、播放、搜索、键盘或模态弹窗覆盖主界面时隐藏系统标签栏，退出后按路由和转场状态恢复。
- 热门海报按内容区域宽度与文字缩放计算列数，避免侧栏展开后仍按整屏宽度布局。
- 推荐列表在 MobX Observer 内读取列表快照，使首次请求、分页追加和标签查询完成后立即刷新，修复冷启动必须先切换标签才能显示内容的问题。
- 播放页支持窄屏上下布局、宽屏视频/选集双栏、系统报告的水平/竖直折叠分区布局和显式全屏。播放器组件在布局切换时保持挂载。
- 展开的宽屏使用左右分栏：左侧整列为黑色播放区域，视频按原始比例居中；右侧显示选集和评论，两栏直接相接。播放背景延伸到安全区，控件单独避让；全屏侧栏固定覆盖窗口，收起时不会将播放容器压成零尺寸，选集组件也不会重复挂载。
- iOS 点击全屏会主动请求横屏，无需先旋转手机；退出全屏、关闭播放页后释放方向限制，连续点击按顺序处理。
- iOS 播放控制改为左上标题胶囊、右上“选集 / 更多”胶囊和底部居中的玻璃控制条。视频背景铺满播放区域，保持视频原比例；只对实际与相机重叠的标题或控制条做局部水平避让，内屏及普通比例窗口保持居中。
- 播放页隐藏系统时间与 Wi-Fi 状态区，退出后恢复；竖屏视频和下方选集内容使用全宽，不再为相机保留整列空白。
- 播放菜单支持渐显、缩放与退出动画；修复 iOS 自适应滚动条重复套用窗口安全区后出现在菜单中间的黑线。菜单保留触摸滚动，减少动态效果时直接切换。
- 播放器玻璃控件只在实际控件区域接收指针事件，空白视频区域支持反复单击显示／收起控件、双击暂停／继续播放。底部控制条使用 32pt 连续圆角，背景裁切与边缘描线共用轮廓。
- iOS 设置首页及二级设置内容延伸至底部安全区，使用渐变半透明模糊；最后一项仍可滚动至安全区上方。
- 推荐页在系统侧栏留有空位时将返回顶部按钮放在导航一侧，其余布局保留页面回顶按钮。再次点选推荐标签也可回到列表顶部。

## 构建

需要 Flutter **3.50.0**、Xcode **27.1 或更新**、CocoaPods、CMake >= 3.22 和 Ninja。SDK 版本与最低运行版本是两回事：构建使用 iOS 27.1+ SDK，本项目最低运行版本为 **iOS 15**。

```sh
bash tool/flutterw pub get
bash tool/flutterw analyze --no-fatal-infos --fatal-warnings
bash tool/flutterw test
bash tool/build_ios27.sh
```

`dist/Kazumi_iOS27_unsigned.ipa` 是未签名包，需要自己的 Apple 开发者签名或侧载工具重新签名。脚本同时生成 SHA-256 和 `BUILD_INFO.txt`，记录实际包版本、SDK、源码提交和工作区状态；没有上传或发布远端仓库。

iOS 图标原图保存在 `assets/images/logo/logo_ios.png`，透明区域按深棕色合成的构建源为 `logo_ios_opaque.png`。预先合成可避开 flutter_launcher_icons 0.14.4 的半透明像素颜色通道计算错误；原图保持不变。`flutter_launcher_icons.yaml` 固定使用该构建源；运行 `dart run flutter_launcher_icons` 可重建所有 iOS 尺寸。生成的 `AppIcon.appiconset` 一并提交，后续打包无需重新生成；其他平台图标不受影响。

替换原图时可用 FFmpeg 更新不透明构建源，再生成尺寸资源：

```sh
ffmpeg -f lavfi -i 'color=c=0x554943:s=1024x1024' -i assets/images/logo/logo_ios.png -filter_complex '[0:v][1:v]overlay=format=auto:shortest=1,format=rgb24' -frames:v 1 -update 1 -y assets/images/logo/logo_ios_opaque.png
dart run flutter_launcher_icons
```

GitHub 的 iOS 构建会先检查 SDK；运行器必须安装并选择 Xcode 27.1+。如果系统有多个 Xcode，可以设置 `DEVELOPER_DIR=/Applications/Xcode_27.1.app/Contents/Developer`。

GitHub Actions 的 iOS 任务可通过仓库变量 `IOS_RUNNER` 指定运行器标签；未配置时沿用 `macos-latest`，并继续由 SDK 检查阻止过旧环境构建。上游使用的 `xcode-27` 标签不保证在个人仓库可用，配置前应确认对应运行器已注册。

## 发布前检查

发布前仍需在 Device Hub 的 iPhone Duo 模拟器和真机完成以下完整回归：

1. 外屏与内屏之间切换、四个旋转方向、半折叠和左右分屏。
2. 导航、搜索、弹出菜单和播放器控件避开相机、状态区域与折线。
3. 播放过程中折叠保持集数、播放进度、弹幕与音频连续；全屏和画中画返回正常。
4. 系统深浅色、透明度滑块、降低透明度、增强对比度、减少动态效果、VoiceOver 和大字号。
5. 真实规则源搜索、解析、下载和后台播放；自动化布局测试不替代联网播放或设备验证。
