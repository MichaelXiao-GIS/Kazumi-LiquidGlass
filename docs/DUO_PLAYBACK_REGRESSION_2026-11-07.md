# iPhone Duo 播放回归与测试版 0014

2026-11-07，在专用 `Kazumi Release QA Duo` / iOS 27.2 模拟器上完成本次回归。最终复测应用为 `2.4.3+20405`；发布标签为 `v2.4.3-ios27.1-test.r0014`。后半程将该设备通过 Device Hub 的 **Open in New Window** 单独打开，避免与其它项目的模拟器测试争用同一窗口。

## 本次修复

1. **暂停后拖动进度条意外恢复播放。** 原实现只要正常结束拖动就调用播放；现在恢复拖动开始前的状态。正在播放时拖动仍继续播放，暂停时拖动保持暂停；取消拖动同样保留原状态。换集使旧拖动会话失效时，不得启动新播放器。
2. **搜索服务失败被误报为没有找到番剧。** 保留搜索请求异常，区分有效空结果与请求失败。401/403 提示切换番剧条目加速方式，其它网络失败提示检查网络，提供重试和网络设置入口。分页失败保留已有结果并重试原偏移，旧请求的错误不能覆盖新搜索。

本版没有更换折叠布局或播放器所有权结构：内外屏、旋转和全屏切换中，实测同一集的播放器实例保持不变。

## 播放场景与证据

实际播放《葬送的芙莉莲》（条目 400602），giriGiriLove / cht 线路第 01、02 集，每集约 26:01。通过界面操作并读取运行中播放器的集数、位置、播放标志、倍速和实例标识核验；没有用测试脚本改变这些状态。

| 场景 | 结果 |
| --- | --- |
| 正在播放时外屏 → 内屏 → 半折叠 | 画面继续播放，同一播放器；初轮位置 57.140 → 71.154 → 90.131 秒 |
| 暂停时内屏 → 外屏 → 两侧横屏 | 暂停标志保持，位置精确保持 99.933 秒 |
| 暂停进入全屏，再展开内屏 | 全屏标志保持，位置仍为 99.933 秒 |
| 恢复播放后在全屏中旋转、展开、合上 | 继续播放，未重置进度或重建播放器 |
| 普通播放下半折叠旋转 | 左右或上下分区正确；视频与选集区分别可用 |
| 进入和退出全屏 | 全屏标志正确切换；恢复普通播放布局；第二集退出后仍在 84.459 秒继续播放 |
| 1.5 倍速下展开、旋转及全屏 | 同一播放器，倍速仍为 1.5；最终复测采样位置 1209.416 秒 |

| 全屏打开/关闭选集面板并切换第 02 集 | 面板正常覆盖视频；集数变为 02，新播放器正常起播 |

换集会按现有设置重新使用默认倍速（本次为 1.0）；同一集的折叠、旋转和全屏转换保留当前倍速。正常打开历史记录会按既有自动播放设置开始续播，并不恢复上一页面退出时的暂停状态。

## 验证边界

- 本轮覆盖上述播放控制、折叠、旋转、全屏、换集及正常历史续播；不是所有网络源、长时间后台播放、系统中断或音频输出的认证。
- AGE 线路返回了时长约 3 秒的“视频加载失败”视频，因此未用于连续播放判断；giriGiriLove 的完整视频用于回归。
- 当前分支构建没有上游镜像服务的签名凭据，受保护的搜索接口会拒绝请求。本次修复错误呈现和恢复入口，不提供或伪造凭据，也不保证切换线路后所有网络都可达。条目 ID 入口可用于访问已知番剧。
- 本次自动弹幕加载出现失败提示，未将弹幕服务判为通过。实机音频、画中画、DLNA、VoiceOver 和长时间性能测试仍属于独立验证范围。
- 调试期间一次热更新发生框架加载错误；重新构建安装后复测，未在新安装版本观察到该错误。热更新中断后的画面不作为发布验证依据。
